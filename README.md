# MGAvatar

> **仓库已迁移**：本项目已并入 MGHUB Typecho 合集仓库 [MGBlogSuite](https://github.com/ReeskySUI/MGBlogSuite)，后续更新仅在合集仓库发布。本仓库自 v1.1.4 起归档只读，历史版本与发布包继续保留。

Typecho 插件：用 URL 图片彻底替换 Gravatar 头像，无需修改 Typecho 源码。插件自包含，不依赖任何主题，可单独安装使用。

## 解决的问题

Typecho 的评论头像、后台个人设置头像默认通过邮箱哈希请求 `secure.gravatar.com`，国内访问缓慢或失败。MGAvatar 接管这些位置，全部改为直接显示 URL 图片。

## 使用方法

1. 管理员在「插件」页面启用 MGAvatar。
2. **每位用户**进入后台「个人设置」页，在**表单区最上方**的 **MGAvatar** 设置区，在「头像 URL」填写自己的图片地址并保存。
3. 管理员可在插件设置中填写「全局默认头像地址」，用于没有填写个人头像的用户。

## 头像来源规则

1. **注册用户的评论**：显示该用户在「个人设置 → MGAvatar → 头像 URL」中填写的图片。
2. **匿名访客评论**：显示插件设置中的「全局默认头像地址」。
3. 全局默认地址留空时，使用插件自带的默认头像（`assets/default-avatar.png`）。
4. **后台个人设置页**顶部的头像同步替换为个人头像或默认头像，并移除指向 gravatar.com 的链接（可在插件设置中关闭）。

## 安装

1. 将 `MGAvatar` 文件夹上传到 Typecho 的 `usr/plugins/` 目录。
2. 后台「插件」页面启用 MGAvatar。
3. 进入「个人设置」填写头像 URL。

## 边界

- 插件不提供图片上传功能，头像地址可使用任意图床或站内上传的图片（例如在“撰写文章”页上传后复制链接）。
- 引用（pingback/引用通告）不显示头像，这是 Typecho 的默认行为。
- 停用插件后头像恢复为 Gravatar。
- 插件配置在不同 Typecho 版本中存储格式不同（JSON 或 PHP serialize），插件读取时自动识别，无需手动处理。
